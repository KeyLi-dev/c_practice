# C Primer Plus 课后习题 · 个人重构进阶版仓库
## 仓库说明
本仓库存放《C Primer Plus》全书课后编程练习题，**并非书本官方极简标准答案**。

### 编写思路
1. 完整系统学习完《C Primer Plus》整本书后，以练习C为目的，对整本书所有章节的编程练习题做练习
2. 养成模块化编程思维 拆分功能，练习编写代码的思路
3. 并非标准答案，只是按照自己的思路编写的练习代码

### 目录结构
- unit_01 ：第一章课后练习代码
- unit_02 ：第二章课后练习代码
- ...
每个文件夹内 _x_x.c 对应章节和题号
